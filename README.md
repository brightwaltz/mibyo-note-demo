# 未病ノート デモ / MIBYO NOTE (demo)

二十四節気を軸に「今日の体調」を12項目で記録し、記録直後に **共感カード**（同じ節気に同じ不調を答えた人の数・割合）と **去年の同じ時期との比較** を返すプロトタイプです。

**公開URL:** https://brightwaltz.github.io/mibyo-note-demo/

## 仕様（運用費 月額0円）

- 静的HTML 1枚のみ。サーバー処理なし・データベースなし・外部への送信なし
- 入力内容は閲覧端末のブラウザ内（localStorage）にのみ保存されます
- 画面上の人数・他者データ・法人ダッシュボードの数値は **すべて端末内で生成したサンプル** です。実在の個人・企業のものではありません

## 位置づけ

本デモは検討用の試作であり、医療行為・診断・治療を目的としたものではありません。
